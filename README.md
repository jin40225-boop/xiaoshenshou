# 我家小神獸 · 神獸家族父親節活動提案網站

115 年度新竹市神經多元性家庭支持計畫－神獸家族父親節活動的提案介紹網站。
把 ADHD 孩子的特質，溫柔轉譯為獨一無二的「小神獸」。

- 主辦資助：扶輪社東門分社
- 協辦執行：社團法人台灣白露社會福利服務協會、公民行動
- 成果節點：115 年 8 月 8 日 父親節

## 技術

純靜態網站（HTML / CSS / JS），電影分鏡式捲動敘事。

- `index.html`／`styles.css`／`app.js`
- `vendor/` 自帶函式庫：[GSAP + ScrollTrigger](https://gsap.com)、[Lenis](https://github.com/darkroom-engineering/lenis)、[SplitType](https://github.com/lukePeavey/SplitType)
- `img/` 水彩插畫（WebP）、`assets/` 協會識別

不依賴外部 JS CDN，可離線於會場展示。以 GitHub Pages 部署。
